# 《廉頗藺相如列傳》範文導讀

漢華中學中國語文科｜中四至中六自學／課堂投影頁

## 檔案

| 檔案 | 用途 |
|------|------|
| `index.html` | 單檔教學網頁（導讀、字詞、章法、自測 60 題、影片） |
| `Code.gs` | Google Apps Script：接收學生交卷，寫入試算表 |
| `README.md` | 本說明 |

## 快速開始（學生端）

1. 用瀏覽器直接開啟 `index.html`（或放上 Google Drive／校本網頁空間）。
2. 填寫**班別、學號、姓名**。
3. 依序完成「內容理解／字詞解釋／寫作手法」三節自測（各 20 題，即時對錯與解說）。
4. 全部完成後按「交卷至老師試算表」。

> 若尚未設定 `GAS_WEBAPP_URL`，成績仍會顯示，並以本機 `localStorage` 暫存草稿；頁面會提示「試算表未設定」。

## 老師設定：交卷試算表

1. 已預備試算表：[廉頗藺相如列傳｜範文導讀交卷紀錄](https://docs.google.com/spreadsheets/d/1UeZ0gNM9ZnpMBq_XdMJ62n1EaI2Y0GRE4zZw6aS9k1E/edit)（ID 已寫入 Code.gs）。亦可另開新表。
2. **擴充功能 → Apps Script**，刪去預設內容，貼上 `Code.gs` 全部程式碼。
3. （可選）若腳本**未**綁定該試算表，在 `Code.gs` 填寫：
   ```js
   var SPREADSHEET_ID = '你的試算表ID';
   ```
4. 在編輯器選取函式 `setup` → **執行**一次（授權試算表存取）。會建立分頁「**交卷紀錄**」與表頭。
5. **部署 → 新增部署 → 網頁應用程式**：
   - 說明：可填「廉頗導讀交卷」
   - 執行身分：**我**
   - 具有存取權的使用者：**任何人**
6. 授權並複製「網頁應用程式」網址。
7. 開啟 `index.html`，在腳本最上方把網址貼入：
   ```js
   const GAS_WEBAPP_URL = 'https://script.google.com/macros/s/……/exec';
   ```
8. 用瀏覽器開啟該網址（GET）應見到 `{"ok":true,...}`，即健康檢查通過。

### 交卷紀錄欄位

時間、班別、學號、姓名、內容理解得分、字詞解釋得分、寫作手法得分、總分、滿分、百分比、備註（錯題摘要）

## 老師設定：影片

在 `index.html` 腳本頂部：

```js
const YOUTUBE_ID = '';  // 只填影片 ID，例如 abcdEFGHijk
```

留空則顯示佔位框與提示；標題連結文字為「寶寶老師陪你快速溫範文｜第一集《廉頗藺相如列傳》」。

## 題庫來源

自測三節題目**完整採用** Edcafe 檔（不另造新題）：

- `05_廉頗藺相如列傳_內容理解.html`（20）
- `05_廉頗藺相如列傳_字詞解釋.html`（20）
- `05_廉頗藺相如列傳_寫作手法.html`（20）

選項顯示時會洗牌；來源陣列第一個選項為正確答案。

## 注意

- 無需外掛 JS 框架；字體優先系統 CJK／Noto Sans TC。
- 交卷以 `fetch` + `text/plain` 送 JSON，配合 Apps Script `doPost`，避免 CORS 預檢問題。
- 請勿把含學生姓名的試算表公開分享給「網路上的任何人」編輯；網頁應用程式「任何人」僅指可呼叫交卷介面。
